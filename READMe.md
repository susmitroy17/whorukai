**September 2025**

A proactive monitoring workflow using scheduled PowerShell to perform ICMP ping sweeps, Windows service validation, and SQL database heartbeat checks. Failures are written into a structured SQL event table for incident creation before end-user impact.

A reporting pipeline that ingests 1,000+ mock ServiceNow incidents into normalized SQL, detects operational hotspots by category/time/department, and visualizes SLA-breach patterns through Looker Studio heatmaps.

## ▶️ Run locally

Because the portfolio is a static HTML experience, it does not require a backend server.

### Option 1 — Open directly

Open:

```text
Susmit.portfolio.html
```

in a modern browser.

### Option 2 — Local HTTP server

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000/Susmit.portfolio.html
```

Using a local HTTP server is preferable when testing relative assets and browser behavior.
