## 2025-02-17 - Keyboard Accessibility for Custom Div Buttons
**Learning:** In purely static HTML projects without complex JS frameworks, custom UI elements like hamburger menus are often created using `div` elements with `onclick` handlers. These lack native keyboard accessibility (like `Enter`/`Space` activation) and screen reader support out of the box, leading to inaccessible navigation for non-mouse users. Furthermore, relying only on custom cursors often obscures focus states for keyboard users.
**Action:** When implementing or fixing custom interactive elements (like a `div` acting as a button), always add `role="button"`, `tabindex="0"`, an `aria-expanded` state if it's a toggle, and explicit keydown event listeners (`Enter` and `Space`). Pair this with a global `:focus-visible` CSS rule utilizing existing design tokens to ensure explicit visual feedback for keyboard navigation.
