## 2024-10-25 - Converting DIV to BUTTON for Hamburger Menu
**Learning:** When converting a non-interactive `div` (acting as a menu hamburger) to a semantic `button`, the default user-agent styles (like background, border, and outline) can disrupt existing aesthetic designs. Furthermore, removing the default outline (`outline: none`) removes the keyboard focus indicator, which is a major WCAG violation for keyboard-only users.
**Action:** Always explicitly strip unwanted default styles (`background: transparent; border: none;`) while explicitly defining a new `:focus-visible` state using a project's theme variables (like `var(--accent)`) and adjusting `outline-offset` to ensure the focus state is both visible and aesthetically pleasing. Also, ensure ARIA attributes like `aria-expanded` are dynamic based on interaction state.
