## 2024-09-24 - Converting Visual DOM Nodes to Semantic Buttons
**Learning:** When converting visually styled interactive `div` elements (like a custom hamburger menu) into semantic `<button>` elements for accessibility, the default button styling (`background: transparent; border: none; outline: none;`) must be explicitly stripped to prevent visual regressions while keeping the existing padding and width intact. Additionally, `aria-expanded` states must be manually managed as strings (`'true'` or `'false'`) in JavaScript to accurately represent state changes to screen readers.
**Action:** When making custom UI elements accessible, always use `<button>` instead of `<div>` or `<a>`. Ensure `aria-expanded` and keyboard `:focus-visible` styles are manually applied and verified.
