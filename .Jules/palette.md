## 2026-09-27 - Converted Hamburger Menu `div` to `button` for Accessibility
**Learning:** When changing interactive elements (like a hamburger menu) from generic tags (like `div`) to semantic elements (like `button`) in an environment without a standard UI framework or package.json, be highly aware of default browser styles for native elements. You have to actively unset `background`, `border`, and `outline` attributes for the button. Additionally, the dynamic state (`aria-expanded`) has to be set and toggled using string representations (`'true'` and `'false'`) with standard JavaScript `setAttribute` to be interpreted correctly by screen readers.
**Action:** When converting generic elements to interactive semantic elements in vanilla web components, always include explicit default style resets and stringify ARIA attributes in JS state handlers.
