## 2025-02-23 - Hamburger Menu Semantic Upgrades
**Learning:** When converting interactive `div` elements (like a hamburger menu) to semantic `<button>` elements for better screen reader and keyboard accessibility, it's critical to strip default button styles (background, border, outline) to prevent visual regressions while ensuring a visible focus indicator (e.g., `:focus-visible`) is added. Additionally, dynamic menu buttons require explicit management of the `aria-expanded` attribute, toggling it between `"true"` and `"false"` (as strings) to ensure screen readers correctly interpret the current state of the interactive element.
**Action:** Always verify that converted `button` elements have default styles stripped, a custom `:focus-visible` state added, and `aria-expanded` attributes accurately synced with the component's internal open/closed state.
