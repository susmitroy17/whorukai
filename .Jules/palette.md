## 2024-11-02 - Keyboard Accessible Hamburger Menus
**Learning:** Converting interactive `div` elements to `<button>` tags for accessibility requires careful handling of default button styles (`background`, `border`, `outline`). When stripping the default `outline` for visual design purposes, a custom `:focus-visible` state must be provided to ensure keyboard users can still see when the element is focused. Additionally, interactive menus must communicate their state via `aria-expanded` attributes that are dynamically toggled by JavaScript.
**Action:** When converting non-semantic interactive elements to buttons, always explicitly reset default button styles, add a custom `:focus-visible` outline using the site's accent color, and implement dynamic `aria-expanded` toggling in the associated JavaScript click handlers.
