## 2024-05-20 - Hamburger Menu Accessibility
**Learning:** When converting interactive `div` elements (like a hamburger menu) to semantic `<button>` elements for keyboard accessibility, default button styles can break the existing layout. Stripping default button styles (background, border, outline) removes focus indicators, which violates WCAG guidelines unless a custom `:focus-visible` style is provided. Additionally, dynamic menu states require programmatic toggling of `aria-expanded` to ensure screen readers correctly interpret the open/closed state.
**Action:** Always strip default `<button>` styles (`background: transparent; border: none;`) when replacing `div`s, ensure `outline: none;` is accompanied by a custom `:focus-visible` style using existing CSS variables, and programmatically toggle `aria-expanded` between `'true'` and `'false'` as strings in the JavaScript.
