## 2025-02-14 - Semantic Button Conversion for Custom Hambuger Menus
**Learning:** Converting standard `<div>` based hamburger menus to semantic `<button>` elements requires explicitly resetting default button styles (like `background: transparent; border: none;`) while concurrently providing a custom `:focus-visible` outline that fits the design language, as browser default outlines are frequently disabled or insufficient in custom themes. Furthermore, screen readers need dynamic state updates on this new `<button>` via the `aria-expanded` attribute, which must be passed strictly as string values ('true'/'false') in JavaScript.
**Action:** When converting custom interactive elements to semantic HTML buttons, always combine structure changes with explicit style resets, custom keyboard focus styles, and dynamic ARIA state management in JS.
