## 2025-10-24 - Interactive Elements & Keyboard Focus
**Learning:** Found that custom interactive elements like hamburger menus were implemented as `<div>`s instead of semantic buttons. This completely bypasses native keyboard focus (tabbing) and interaction (Enter/Space), severely impacting keyboard and screen reader accessibility. Additionally, a global `:focus-visible` outline was missing, leaving users without a clear focus indicator on links and interactive elements.
**Action:** Always prefer native semantic HTML (`<button>`) for interactive elements rather than binding clicks to `<div>` or `<span>` tags. Apply `.navbar__hamburger { background: transparent; border: none; }` to reset default button styles, and implement a global `:focus-visible` rule using theme colors to guarantee keyboard navigation visibility.
