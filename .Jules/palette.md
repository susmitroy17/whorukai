## 2025-02-18 - Hamburger Menu Accessibility
**Learning:** When converting interactive `div` elements like hamburger menus into semantic `<button>` tags for accessibility, it is essential to strip default button styles (`background: transparent; border: none; outline: none;`). Furthermore, managing dynamic menu states requires explicitly setting the `aria-expanded` attribute dynamically using strings ('true' or 'false'). Finally, when removing the default outline, providing a customized `:focus-visible` state is critical to prevent WCAG violations and preserve keyboard accessibility.
**Action:** Always check for interactive `div`s that behave like buttons and upgrade them to semantic `<button>` elements, ensuring that custom focus states are explicitly added, default styles are removed, and related ARIA states (`aria-expanded`) are properly managed in JavaScript via strings.
