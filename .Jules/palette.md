## 2023-10-27 - Converting div to semantic button
**Learning:** In this codebase, when converting `div` elements to `<button>` for accessibility, we must explicitly strip default button styles (`background: transparent; border: none;`). If removing default outlines (`outline: none;`), a custom `:focus-visible` style must be provided (e.g., using `var(--accent)`) to maintain keyboard accessibility and prevent WCAG violations. When managing dynamic menu states (e.g., hamburger menus), `aria-expanded` must be programmatically toggled between `'true'` and `'false'` (as strings) to ensure screen readers correctly interpret the state.
**Action:** When converting div to button, explicitly strip default styles and add focus visible outline. For hamburger menu, dynamically toggle aria-expanded attribute.
