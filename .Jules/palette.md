## 2024-10-23 - Converting Div Buttons to Semantic Buttons
**Learning:** When converting dynamic interactive elements (like a hamburger menu `div`) to a semantic `<button>`, stripping default button styles (`background: transparent; border: none; outline: none;`) is necessary. However, removing `outline: none;` removes the default keyboard accessibility focus indicator. This MUST be replaced with a custom `:focus-visible` state (e.g., using an offset outline). Additionally, for dynamic menus, the `aria-expanded` state must be programmatically managed as a string ('true' or 'false') via JavaScript, not just boolean values, for screen readers to announce the state change correctly.
**Action:** Always verify keyboard focus states when converting custom interactive elements to semantic buttons. Use `aria-expanded` and ensure JavaScript dynamically toggles this attribute as a string on the button itself.
