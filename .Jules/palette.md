## 2025-02-27 - Converting dynamic visual elements to semantic toggles
**Learning:** When dealing with visual-only toggle elements (like a hamburger menu `<div>`), replacing them with semantic `<button>` tags reveals default user-agent button styling (background, border) that breaks the UI design unless explicitly removed. Also, JavaScript handling must accurately toggle `aria-expanded` strings between `'true'` and `'false'` for screen readers to properly interpret dynamic overlay states.
**Action:** Always include CSS reset rules (`background: transparent; border: none; outline: none;`) when converting generic containers to `<button>` elements, add `:focus-visible` to utilize existing color tokens for keyboard support, and ensure JS `aria-expanded` updates dynamically map to open/closed boolean states correctly as strings.
