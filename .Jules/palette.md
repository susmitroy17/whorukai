## 2026-09-22 - Converting Custom Interactive Divs to Semantic Buttons
**Learning:** When converting generic `div` elements with custom `onclick` handlers (like hamburger menus) into semantic `<button>` elements for accessibility, it is crucial to explicitly apply button style resets (`background: transparent; border: none; outline: none; padding: 0;`). Without these resets, the browser's default button styles will introduce severe visual regressions, breaking custom UI components and cursor interaction expectations. Additionally, when managing dynamic menu states, `aria-expanded` must be programmatically toggled between `'true'` and `'false'` (as strings) to ensure screen readers correctly interpret the element's state.
**Action:** Always include a CSS reset block for newly converted buttons and verify keyboard navigability and ARIA state toggling via temporary UI tests before committing.
